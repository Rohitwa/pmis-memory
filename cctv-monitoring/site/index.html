Flowchart & System architecture

  • At NVR (store) — 15–30 days of feed kept locally, depending on the storage type.
  • Transport — each store dials out to the auto-register gateway: one outbound TCP session per store; RTSP video, events, and playback all ride this session. No inbound connectivity, no static IPs.
  • Separation — a stream router (media broker, pub/sub): every stream entering the gateway is republished to its subscribers. The inference path holds pinned subscriptions to 2 substreams per store; the live-view path subscribes on demand to any camera and republishes over WebRTC.
  • Live view — pure relay, zero storage; 5% of stores at any time, rotating randomly or adjusted by the viewer.
  • Data analytics — hardware decode (NVDEC) + TensorRT pipelines on 20 GPUs produce the 3 metrics; all metrics visible at HQ locally as well as on cloud. Storage exists only on this path: metrics in a time-series DB + event clips in an object store, 5 TB/month.
